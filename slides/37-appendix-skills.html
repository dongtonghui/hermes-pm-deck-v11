附录 A · 本次工作坊会用到的 Hermes 技能

下面三个技能代表了「把 AI 从聊天框变成工作流」的不同路径：高保真视觉、社区情报、以及 skill 自身的持续进化。

H

huashu-design

花叔 Design：用 HTML 做高保真原型、交互 Demo、幻灯片和动画。
工作流程原理
  • 1 先澄清目标：受众、尺寸、情感基调、输出格式
  • 2 收集真实资产：品牌色、logo、产品图、字体
  • 3 多方向探索：并行产出 3 套差异化视觉方案
  • 4 用 HTML/CSS 交付可点击、可演示、可导出 MP4/GIF 的成品
适用情况
产品 mockup、PPT 幻灯片、交互动画、设计变体评审。
下载与安装
安装：将仓库 clone 到 ~/.hermes/skills/creative/huashu-design/
R

reddit-community-research

整套爬取 Reddit 社区数据，提取问题、情绪信号与功能需求优先级。
工作流程原理
  • 1 确认目标：subreddit、关键词、时间范围、数据量
  • 2 用 pullpush.io 或 Tavily 获取帖子与评论数据
  • 3 整理好：过滤噪音、分类问题、提取情绪关键词
  • 4 输出报告：问题矩阵、需求优先级、可直接引用的高保真原声
适用情况
竞品社区调研、用户需求验证、社交媒体聆听、Reddit 情报。
下载与安装
安装：将仓库 clone 到 ~/.hermes/skills/research/reddit-community-research/
D

darwin-skill

达尔文.skill：像训练模型一样优化你的 Agent Skills，评估 → 改进 → 测试 → 保留或回滚。
工作流程原理
  • 1 选择要优化的 skill，用 9 维度评估体系打分
  • 2 针对最低分维度生成一个具体改进方案
  • 3 独立子 agent 复评，改进有效则保留，否则回滚
  • 4 每轮结束暂停，等人确认后再进入下一轮
适用情况
Skill 质量评估、迭代优化、反模式排查、持续进化。
下载与安装
安装：将仓库 clone 到 ~/.hermes/skills/autonomous-ai-agents/darwin-skill/
如何安装 Hermes 技能： 将 skill 仓库 clone 到 ~/.hermes/skills/\u003ccategory\u003e/\u003cskill-name\u003e/ 目录下，或直接通过 Hermes 内置 skill 管理命令安装。安装后重启 Hermes 或运行 hermes skills list 即可看到新技能。
